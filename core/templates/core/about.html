ABOUT AVERON

One console for the lookups
you'd otherwise do by hand.

AVERON queries public data sources for IPs, domains, phone numbers, MAC addresses, usernames, and directories, and returns the result in one place instead of six browser tabs.

01

Why it exists

Basic OSINT lookups are simple on their own, but doing several of them for the same target usually means switching between separate sites, each with its own layout, limits, and quirks. AVERON puts the common ones behind a single interface, so a lookup takes one query instead of five open tabs.

02

How it works

You enter a value on a module — an IP, domain, phone number, MAC address, or username. Django handles the request server-side, the matching module queries its public source, and the parsed result is shown back to you. There's no local database behind it and nothing is cached between requests.

04

Limitations & responsible use

Every result comes from an external public source, so accuracy, completeness, and uptime depend on that source, not on AVERON. Treat results as a starting point, not a verified record. AVERON is meant for lawful research and checking your own exposure — not for stalking, harassment, or targeting people without a legitimate reason.
